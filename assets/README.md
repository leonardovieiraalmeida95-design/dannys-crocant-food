# Identidade e fontes

A logo SVG foi reconstruída a partir da referência fornecida para esta demonstração. A marca pertence aos seus titulares; a autorização para uso e lançamento oficial ainda está pendente.

As fontes locais foram obtidas do Google Fonts. Cada família inclui sua licença OFL em fonts/. Os arquivos WOFF2 cobrem os conjuntos Latin e Latin Extended.

Para refazer a imagem de compartilhamento e o ícone Apple: node scripts/generate-brand-assets.mjs.
